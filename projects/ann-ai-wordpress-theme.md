# ANN — AI-Powered WordPress Theme Localization

## Overview

ANN is an AI-powered, multipurpose WordPress theme introduced to the Persian WordPress market through RTLTheme (Rastchin). It brings AI-oriented features into a Persian-market-ready WordPress theme experience.

My contribution focused on the complete Persian localization of the theme and its bundled plugins, taking the project from language-file translation through demo localization and front-end styling refinement.

## Project Links

- **Product Page:** [ANN WordPress Theme on RTLTheme](https://www.rtl-theme.com/ann-artificial-intelligence-wordpress-theme/)
- **Live Demo:** [anndemo.motlaqcode.ir](https://anndemo.motlaqcode.ir/)

## Role

**WordPress Theme Localization & RTL Adaptation**

I was responsible for the end-to-end Persian localization process, including:

- Translating the theme's language files and the language files of its bundled plugins, covering more than 40,000 lines of translation.
- Localizing the theme demos after completing the language-file translation.
- Refining and adjusting CSS so that Persian demo layouts and visual styling closely matched their English counterparts.
- Reviewing the localized experience across the theme demos to ensure a consistent Persian presentation.

## Scope of Work

The localization work went beyond translating visible strings. It covered the theme and companion plugin language resources, the Persian presentation of the demo content, and the CSS refinements needed to preserve the original design quality across languages and text directions.

The goal was to deliver a Persian version that felt like a carefully adapted counterpart of the original theme, rather than a translated interface with visibly inconsistent layouts.
